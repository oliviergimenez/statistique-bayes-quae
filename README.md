Vous trouverez ici tout le matériel concernant le livre [**Introduction à la statistique bayésienne avec R**](https://oliviergimenez.github.io/statistique-bayes-quae/) écrit par Olivier Gimenez, et plus précisément :

-   Les fichiers `R Markdown` qui contiennent le code `R` et le texte pour reproduire les différents chapitres : [`index.Rmd`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/index.Rmd), [`01-principes.Rmd`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/01-principes.Rmd), [`02-methodesmcmc.Rmd`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/02-methodesmcmc.Rmd), [`03-misenoeuvrepratique.Rmd`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/03-miseenoeuvrepratique.Rmd), [`04-priors.Rmd`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/04-priors.Rmd), [`05-regression.Rmd`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/05-regression.Rmd), [`06-glms.Rmd`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/06-glms.Rmd) et [`07-conclusions.Rmd`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/07-conclusions.Rmd).

-   Les scripts `R` nettoyés du texte pour vous permettre de faire tourner le code plus facile : [`scriptsR.zip`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/scriptsR.zip).

-   Les applications interactives ou `shinyApps` permettant d’explorer de manière visuelle et intuitive plusieurs concepts clés abordés dans le livre (priors, MCMC, régression, modèles hiérarchiques) : [`shinyApps.zip`](https://github.com/oliviergimenez/statistique-bayes-quae/raw/refs/heads/main/shinyApps.zip).
